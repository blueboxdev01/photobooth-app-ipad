# v0.14.0-ipad — MemoStills, and a gallery of every guest

**Download `photobooth-v0.14.0-win-x64.zip`, unzip, run `Photobooth.Server.exe`.**
Then open <http://localhost:5000/operator>.

> The version at the foot of the rail reads **`0.14.0-ipad`**. Please quote it
> with any result.

## The console has been rebuilt

New name, new look. The rail now reads in the order a night actually runs:

| | |
|---|---|
| **Start Session** | Run the booth |
| **Guest Gallery** | Find a guest's photos |
| **Templates** | Frame and layout |
| **Settings** | Folders, wifi and health — at the foot, because it is set up once |

**Setup is now called Settings**, and it is the same page with everything it
always had: folders, wifi, the address picker, timings, delivery, backdrop and
the health readout. Every instruction in the guides has been updated to match.

The **camera status and the two folders** moved out of the rail into a strip
across the top, since they are true whichever page you are on. The **session
controls moved beside the shots** in a fixed-width column, so a button never
moves between states — you reach for Accept while talking to a guest, and where
it is matters more than which ones happen to be live.

Light and dark both, as before.

## New: Guest Gallery

The thing the console could not do. A guest comes back an hour later having lost
their link, or emails next week — and until now the only answer was to go
digging through dated folders in Explorer.

Every session is now on one page, newest first, each with its strip so you can
recognise it at a glance, and links to the strip, the GIF and every photo.

It is **read-only on purpose**. Deleting a guest's photos is a real decision and
the output folder is the right place to make it deliberately, rather than from a
button that can be brushed past mid-event.

## What to look at

1. Open the console. The rail, the top strip and the session controls should all
   be where this describes.
2. Run a session, then open **Guest Gallery** — it should be there with its
   strip and a **GIF** link.
3. Switch between light and dark at the foot of the rail. Both should be
   comfortable; the dark one is what the booth actually runs in.
4. **Settings** — check everything you used to reach under Setup is still there.

If anything you relied on has gone missing rather than moved, that is the
result worth sending back.

## Everything else

Unchanged from v0.13.0: the looping GIF of each strip, sharp photos in the
strip, guest photos over your wifi, the address picker, and the iPad guest
display.

Still outstanding, unchanged: a custom backdrop set in Settings does not reach
the iPad, which keeps its default dark background.
