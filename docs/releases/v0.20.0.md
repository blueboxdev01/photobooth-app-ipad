# v0.20.0 — Mac booth, iPad preview, Windows claiming station with a guest monitor

**Windows: `photobooth-v0.20.0-win-x64.zip`. Mac (Apple Silicon): `photobooth-v0.20.0-macos-arm64.zip`.**
Set up with **[docs/SETUP-GUIDE.md](../SETUP-GUIDE.md)**, step by step. Install it on **both** the Mac
and the Windows laptop: the station reads the wifi details only a v0.20.0 booth publishes.

## The layout

- **MacBook**: the booth. Camera, every photo, every setting. Accept and Retake are pressed here.
- **iPad**: the guest preview. No mirror, no certificate.
- **Windows laptop + external monitor**: the claiming station. The operator searches on the laptop;
  the monitor facing the guest shows only the guest being served.

## What changed

- **The iPad opens the display over plain http.** `http://<mac>.local:5001/display`, nothing to
  install or trust. The old `https://...:5002` address still works for an iPad already set up.
  Set the iPad's Auto-Lock to Never, as Safari will not keep a plain-http page awake.
- **Each photo fills the iPad for 2 seconds** as it lands, with the next count in the corner, then
  joins the row. After the last shot the strip preview follows, then the guest's number.
- **A guest-facing monitor on the claiming station.** `/pickup/screen` shows one guest's strip and
  QR. Clicking a strip on `/pickup` puts it there; **Esc** clears it, and it clears itself after
  3 minutes. The grid of every guest stays on the operator's screen.
- **The Mac sets the wifi for both machines.** The booth writes the wifi name and password into the
  shared sessions folder (`booth-settings.json`); the claiming station uses them, and its Settings
  page says so. Change them on the Mac only.

## Privacy fixes

- **Raw photos are no longer fetchable from the wifi.** `/api/photos/IMG_0042.JPG` served any shot
  in the watch folder to any phone on the network, under names that can be counted through. From
  the network it now serves only the shots of the session on screen.
- **`/api/claim` no longer lists guests' links** unless the booth actually uses the old `/claim`
  station. With hand-over by number, nothing needs that list.

## Also

- The operator console finds shots in EOS Utility's dated subfolders by name (the follow-up to
  v0.19.2), and Diagnostics lists files from those subfolders.
- The test booth runs against its own settings and templates, so a layout changed by hand on a
  developer's machine no longer fails the end-to-end tests.
