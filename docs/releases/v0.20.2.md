# v0.20.2 — Clear steps for saving the video on an iPhone

**Windows: `photobooth-v0.20.2-win-x64.zip`. Mac (Apple Silicon): `photobooth-v0.20.2-macos-arm64.zip`.**
Only the guest download page changed, which the **Windows claiming station** serves, so that is the
machine that needs it. Setup is unchanged: [docs/SETUP-GUIDE.md](../SETUP-GUIDE.md).

## The fix

On an iPhone, **Save the video** offered only "download as a file" or Google Drive, and the video
did not reach Photos. The file is fine (a standard H.264 MP4); the limit is the iPhone's: a
plain-http page cannot put a video straight into Photos, and Safari has no touch-and-hold
*Add to Photos* for videos.

So the guest page now prints the way in, **right under the Save the video button**:

1. Tap **Save the video**, then **Download** (or **Save to Files** if that sheet opens).
2. Open the downloads: the download arrow in Safari's address bar, or Files > Downloads.
3. Tap the video.
4. **Share**, scroll down, **Save Video**.

Android is one line: it goes to Downloads and shows in the Gallery. Photos are unchanged: touch
and hold, **Add to Photos**.

Everything else is as [v0.20.1](v0.20.1.md).
