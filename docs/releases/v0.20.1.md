# v0.20.1 — No number on the photos, and a video that saves to Photos

**Windows: `photobooth-v0.20.1-win-x64.zip`. Mac (Apple Silicon): `photobooth-v0.20.1-macos-arm64.zip`.**
Install it on both the Mac and the Windows laptop. Setup is unchanged: [docs/SETUP-GUIDE.md](../SETUP-GUIDE.md).

## Fixes

- **The guest's number is no longer drawn on the strip or the video.** It is for finding the guest
  at the claiming station, so it stays on the iPad and in `session.json` and nowhere a guest posts.
- **The video can be saved to Photos on an iPhone.** Safari's video player shares only the link, so
  its share sheet had no *Save Video*, just Share and Copy. The guest page now has a **Save the
  video** button that downloads the file. On iPhone: **Download**, the download arrow in the
  address bar, tap the video, **Share > Save Video**. On Android it lands in Downloads and the
  gallery.

Everything else is as [v0.20.0](v0.20.0.md).
